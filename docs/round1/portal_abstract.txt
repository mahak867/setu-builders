Nyay Setu by Setu Builders: grievance redressal you can audit. AI proposes, rules decide, citizens confirm. Working prototype, public code, demo video and live traces: github.com/mahak867/setu-builders

Problem: portals reward closing tickets, not fixing problems. DARPG's own reports show the same problems recurring: over 5.01 lakh grievances in just ten categories during 2022-25. A Pune resident on PMC Care (Free Press Journal, June 2026): "most complaints were simply closed."

How it works (running today on synthetic stand-ins for the three official datasets):
1. PII redaction before any LLM call; Identity-Hiding categories masked from officers.
2. LLM intake agent (gpt-oss-120b on Groq): reads Marathi, Hindi, English or Hinglish, asks for missing details in the citizen's language, builds a draft (category, description, location, urgency, missing details) the citizen confirms. Voice via Whisper large-v3.
3. Independent rule reader cross-checks every case. If they disagree, confidence drops and a human decides. The LLM can only add caution; if it fails, the rules run the whole intake.
4. Case memory: top-3 similar past cases as evidence, matched across languages via the intake agent's English translation.
5. Duplicates grouped by category, place and time; every grievance keeps its own reference number.
6. SLA breach and recurrence prediction; escalation to the supervisor before the deadline.
7. Policy gate: deterministic code on the Category Master, 7 numbered rules. Sensitive cases always go to a human.
8. Actions: database update, department assignment, HMAC-signed webhooks (n8n-ready), WhatsApp/email messages (simulated in the prototype).

Every AI action is logged as AI_SYSTEM (model, confidence, timestamp, reasoning, rule). Each grievance has a public Langfuse trace with every agent step.

Measured, not claimed: 57 adversarial cases through the real pipeline, including 18 held-out cases written after tuning. LLM-led results: 0 sensitive cases auto-routed, 21/21 sensitive cases recognised with identity hidden, 0 closed by AI, 0/10 prompt injections succeeded. Misses are published as found: on its first held-out run the rules-only fallback let one Marathi injection through (since fixed), and the LLM sends some routine cases to a human, the safe direction. 105 automated tests run on every push.

AI cannot close or reject: blocked in the state machine, not by a prompt. AI only marks "Proposed resolved"; the citizen confirms or disputes, and a dispute reopens the case automatically. Priority = severity x urgency x affected population, not raw volume.

All three demo scenarios run in the video: a Marathi streetlight case auto-proposed (AUTO-OK), a Hindi bribe complaint held for a human with identity hidden (CM-SENS), and Marathi/English/Hindi pothole duplicates plus a recurring drain escalated before its SLA (ESC).

Finale: official datasets, PostgreSQL/pgvector, multilingual embeddings, real WhatsApp, hotspot map.
